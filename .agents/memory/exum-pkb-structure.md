name: EXUM PKB single-app structure
description: Product identity and domain-role boundaries for Gustafta EXUM PKB.
---

Use **Gustafta EXUM PKB** as one of the Executive Summary services and **`exum-pkb.gustafta.my.id`** as its application address. The Header entry is **EXUM-PKB**, but it opens the existing general Executive Summary page; that page presents EXUM PKB as one option and links explicitly to the external application. Dokumen Proyek supplies reports, assignments, project evidence, and experience.

**Why:** Two independently evolving EXUM applications would split answers, blueprints, evidence, profiles, estimates, and document history, while confusing users about which application is official.

**How to apply:** Do not route the Header directly to a local PKB builder. Keep the general Executive Summary concept page and place a clear external CTA for EXUM PKB at `exum-pkb.gustafta.my.id`. Treat any Dokumen Proyek EXUM address as a redirect or focused landing page into the same app.
