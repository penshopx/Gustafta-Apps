# AI Builder Access And Monetization

- **Create a new chatbot:** use the manual Blueprint Builder path. Creation requires an active subscription and consumes the account's existing chatbot quota.
- **Customize a system Claw:** requires an individual license or an eligible active Claw package. It creates a private owner copy; edits do not change the system source.
- **Product distinction:** the AI Specialist Store remains the catalog for ready-to-use products; AI Builder is the workspace for creating or privately customizing systems.
- **Management:** the user's created or cloned systems appear in their AI Builder workspace and open in Dashboard.

**Why:** the owner clarified that AI Builder must follow existing monetization rather than invent a new fee, and that creating a new chatbot is different from customizing a licensed system Claw.

**How to apply:** keep access checks and UI copy distinct for manual creation (subscription/quota) and system Claw cloning (per-Claw/package entitlement); never describe cloning as editing the shared source.
