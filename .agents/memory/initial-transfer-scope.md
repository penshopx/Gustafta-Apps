---
name: Initial JavaScript transfer scope
description: Why the release transfer baseline is an anonymous production frontend profile, not a dashboard optimization.
---

Keep the cold-visit transfer gate separate from dashboard optimization and the static HTML asset budget. Its baseline is a fixed anonymous production frontend profile, not a development server or a claim about all live marketing configurations.

**Why:** The user explicitly requested a reproducible production transfer baseline that complements the static budget, not work to shrink the dashboard. Running the full backend would introduce shared-database seeds and changing live API configuration into a byte-budget check.

**How to apply:** Treat changes to login/API/marketing assumptions as a deliberate new measurement profile. Do not silently compare an authenticated page or live pixel configuration against the anonymous baseline.
